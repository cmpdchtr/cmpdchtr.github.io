# cmpdchtrOS

A web-based operating system built for the Hack Club Star Dance jam. It features a classic Windows 7 aesthetic built entirely with vanilla HTML, CSS, and JavaScript.

## Features

- **Window Manager**: Draggable, closable, and minimizable windows with a functional taskbar.
- **Start Menu**: Classic start menu layout with working navigation and shutdown sequence.
- **File Explorer**: A fully functional virtual file system with navigation history.
- **Notes**: A built-in text editor that saves your data locally during the session.
- **Minesweeper**: A fully playable classic Minesweeper clone with original mechanics and SVG icons.

## Running locally

Just open `index.html` in any modern web browser. No npm, no build steps, no dependencies.
